# Contributors

Node Empire is an independent open-source realtime strategy game. It is inspired
by the mechanics of *Seven Kingdoms* but shares no code or assets with it.

## Project leadership

- **Alcartez** — founder, lead architect, and original creator
  ([github.com/Alcartez](https://github.com/Alcartez)).
  Core engine architecture, simulation model, and game design.

## Contributors

Community contributors who submit code, tests, balance changes, documentation,
or playtest reports are credited here. Add yourself in the same pull request that
lands your first contribution, or ask a maintainer to add you.
