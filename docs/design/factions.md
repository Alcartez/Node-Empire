# Node Empire - Factions

## Overview

12 playable factions across 3 categories:
- **Humans (4)**: Mortal races with diverse specializations

## Race Relationship Notes

### Humans

**Hapset**: Tolerant of all humans (80-100), hostile to humanoids (they see them as monsters), wary of fantasy creatures (respect their power)

**Mez**: Opportunistic, maintains relations based on usefulness. Positive with espionage-focused factions (Silk Spinners, Ethereals). Hostile to war-mongers (Breplid)

**Argo**: Trade-focused, generally positive with everyone. Slight preference for civilized races. Negative with aggressive factions

**Breplid**: Xenophobic to non-humans (-50 to -70). Even hostile to other humans they consider "weak" or "foreign"

### Humanoids

**Beetle Soldiers**: Territorial, defensive stance. Hostile to aggressive races. Neutral to industrious races

**Mantis Hunters**: Respect strength, despise weakness. Positive with other predator types (Reptilians). Negative with swarm types (Hive Swarms)

**Silk Spinners**: Information brokers, generally neutral. Positive with intelligence-focused races (Cephalopods, Ethereals). Intelligence network extends to all

**Hive Swarms**: Expansionist, view everyone as potential hive members. Hostile to all non-hive creatures (-30 to -70)

### Fantasy

**Primates**: Adaptable, get along with most races. Respect intelligence (Cephalopods). Neutral with predator types

**Reptilians**: Solitary hunters, generally distrustful. Positive with other predator/hunter types. Hostile to swarm types

**Ethereals**: Psionic communion preference, respect intelligence. Positive with Cephalopods (shared intelligence). Neutral with Primates

**Cephalopods**: Intelligence-focused, view most races as inferior but respect other intelligent beings. Highest positive relations with Ethereals

## Technical Implementation

### Faction Data Structure

```rust
struct Faction {
    id: u8,
    name: String,
    category: FactionCategory, // Human, Humanoid, Fantasy
    bonuses: Vec<Bonus>,
    weaknesses: Vec<Weakness>,
    xenophilia: XenophiliaType,
    best_victory: VictoryType,
}

struct RaceRelations {
    base_relation: i8,  // -100 to 100
    current_modifier: i8, // Dynamic changes
    events: Vec<RelationEvent>,
}

enum XenophiliaType {
    HumanOnly,      // Hapset
    NonHumanOnly,   // Breplid
    NonHive,        // Hive Swarms
    Intellect,      // Cephalopods
    Neutral,        // Silk Spinners
    Universal,      // Most others
}
```

### Race Matrix Lookup

```rust
fn get_base_relation(attacker: FactionId, defender: FactionId) -> i8 {
    RACE_MATRIX[attacker as usize][defender as usize]
}

fn get_effective_relation(attacker: FactionId, defender: FactionId) -> i8 {
    let base = get_base_relation(attacker, defender);
    let xenophilia = calculate_xenophilia_bonus(attacker, defender);
    let events = sum_relation_events(attacker, defender);
    base + xenophilia + events
}
```
